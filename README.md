# Chatbot

This is a simple yet effective chatbot that can handle basic user queries using predefined responses. It is built using HTML, CSS, and JavaScript. The chatbot provides automated replies based on user input and allows users to reset the chat when needed.

## Features

- Responds to predefined queries with relevant answers.
- Displays messages in a chat-style interface.
- Provides quick access to frequently asked questions via buttons.
- Allows users to reset the chat at any time.
- Supports both button clicks and manual text input.

## Technologies Used

- **HTML**: Structure of the chatbot UI.
- **CSS**: Styling for the chatbot interface.
- **JavaScript**: Logic for handling user inputs and bot responses.

## How It Works

1. **User Interaction**:
   - The user types a message in the input field and presses "Enter" or clicks the "Send" button.
   - If the query matches a predefined response, the chatbot replies accordingly.
   - If the input is unrecognized, the chatbot suggests possible queries as buttons.
2. **End Chat Feature**:
   - Users can click the "End Chat" button to reset the chat window.
3. **Suggested Queries**:
   - If a user’s input isn't recognized, the bot offers a list of suggested questions.

## Project Files

- `index.html` – The main file containing the chatbot interface.
- `styles.css` – Contains styling for the chatbot UI.
- `script.js` – Handles the chatbot’s logic and response mechanism.
